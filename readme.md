# Smart Expense Tracker Pro

## Overview

Smart Expense Tracker Pro is a responsive web application developed using HTML, CSS, and JavaScript that helps users manage their daily income and expenses efficiently. The application provides real-time financial tracking, transaction management, filtering options, and data persistence using Local Storage.

---

## Features

- Add Income and Expense Transactions
- Edit Existing Transactions
- Delete Transactions
- Search Transactions
- Filter by Income or Expense
- Real-Time Balance Calculation
- Dashboard Summary Cards
- Dark Mode Toggle
- Responsive User Interface
- Local Storage Support (Data remains after page refresh)

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

---

## Dashboard Modules

### Income Summary
Displays the total income amount.

### Expense Summary
Displays the total expense amount.

### Balance Summary
Calculates and displays the available balance.

### Transaction Management
Allows users to add, edit, search, filter, and delete transactions.
